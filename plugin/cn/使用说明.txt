================================================================
  局部四边重拓扑（LocalQuadRetopo）使用说明        版本 1.4.3
================================================================

这份说明讲怎么安装、卸载和排查安装问题。
具体用法请看同目录的《用户指南.txt》。


一、运行环境
----------------------------------------------------------------

  - Windows 10 或 Windows 11（64 位）
  - ZBrush 2022（2022.0.5 及以上）或 ZBrush 2025
  - 第一次安装时需要联网

插件的计算部分由 Python 完成。安装程序会自动检查电脑上有没有
可用的 Python，没有的话会自动下载安装，不需要手动准备。


二、关于 Python（一般不用管）
----------------------------------------------------------------

安装时，安装程序会按顺序做以下检查：

  1. 电脑上如果已经有 Python 3，并且装了 NumPy 和 SciPy，
     就直接使用它，不再下载任何东西。
  2. 否则自动下载一个只给本插件用的 Python，放在 C:\LQR\python，
     并自动安装 NumPy 和 SciPy。窗口里会依次显示：
         [1/3] Python 下载中 ...
         [2/3] pip 安装中 ...
         [3/3] NumPy 和 SciPy 下载中 ...
     共约 60 MB，视网速需要一到几分钟。只在第一次安装时进行，
     以后升级插件不会重复下载。

这个插件专用的 Python 不会加入系统路径，不会影响电脑上其他软件，
也不会和你自己装的 Python 冲突。卸载时删除 C:\LQR 文件夹即可。

如果主下载地址连不上，安装程序会自动换用国内镜像重试。


三、安装插件
----------------------------------------------------------------

  1. 先保存工程，然后正常退出 ZBrush。
  2. 解压整个压缩包，双击其中的 INSTALL.bat。
  3. 安装程序会自动寻找电脑上的 ZBrush，列出编号让你选择，
     输入编号后回车（直接回车选第一个）。
     - 同时装了 2022 和 2025、两个都想装：运行两次 INSTALL.bat，
       每次选一个。
     - 列表里没有你要的那个（例如装在 D 盘的自定义文件夹）：
       输入 0 回车，再输入 ZBrush.exe 所在的文件夹路径后回车，例如：
           D:\ZBrush 2022.0.5
       （在文件夹里选中 ZBrush.exe，按住 Shift 右键选
        “复制为路径”，粘贴进去即可，带不带 \ZBrush.exe 都行。）
       装过一次之后，下次运行会自动列出这个路径。
  4. 如果需要，安装程序会自动下载 Python（见第二节）。
  5. 窗口最后显示绿色的
         安装完成：局部四边重拓扑 1.4.3
     表示安装成功，按任意键关闭。
     如果下面还有黄色提示“需要手动加载一次”：启动 ZBrush 后点
     Z脚本 > 加载，选择提示里给出的 LocalQuadRetopo.txt。
     只需做这一次，以后启动 ZBrush 会自动加载。
  6. 启动 ZBrush，在 Z插件 菜单里找到“局部四边重拓扑”。

安装程序会放置这些文件：
  - ZBrush 安装目录\ZStartup\ZPlugs64\LocalQuadRetopo.txt
    （插件面板）
  - ZBrush 安装目录\ZStartup\ZPlugs64\LocalQuadRetopo.zsc
    （编译好的插件面板。ZBrush 启动时只加载 .zsc，所以安装程序
      按 2022 / 2025 放对应版本编译好的文件；安装包里没有对应
      文件时，手动加载一次后由 ZBrush 自己生成）
  - C:\LQR\ 文件夹（计算程序、插件专用的 Python，
    以及每次运行的临时文件）

重复安装或升级时，直接再运行一次 INSTALL.bat。被替换的旧文件会
备份到 C:\LQR 里以 backup_ 开头的文件夹中。

中文版和英文版使用相同的文件名，同一个 ZBrush 里只能装其中一个，
后装的会替换先装的。


四、卸载
----------------------------------------------------------------

  1. 退出 ZBrush。
  2. 删除 ZBrush 安装目录\ZStartup\ZPlugs64\ 里的
     LocalQuadRetopo.txt 和 LocalQuadRetopo.zsc（如果有）。
  3. 删除 C:\LQR 文件夹。


五、清理临时文件
----------------------------------------------------------------

每次执行都会在 C:\LQR 里留下几个模型文件，用于失败时排查。
长期使用后可以清理，可以删除的有：
  - 所有 .obj、.log、.claim 文件
  - 名字以 lqr 加数字开头的 .txt 报告文件
  - 以 backup_ 开头的文件夹

不要删除：所有 .py 文件、LqrLaunch.exe、python 文件夹，
以及 lqr_python_path.txt、lqr_zbrush_dirs.txt。
误删了也没关系，重新运行一次 INSTALL.bat 即可恢复。


六、安装问题排查
----------------------------------------------------------------

  ■ 提示 Python、pip 或 NumPy / SciPy 下载失败
    → 检查网络后重新运行 INSTALL.bat，已下载的部分会重新开始。
      公司网络可能拦截下载，可以换个网络试试。

  ■ 想改用插件专用的 Python（例如自己的 Python 出了问题）
    → 在 INSTALL.bat 所在的文件夹地址栏输入 cmd 回车，在打开的
      窗口里输入下面这行并回车：
          INSTALL.bat -InstallPython

  ■ 提示 ZBrush 正在运行
    → 保存并退出 ZBrush 后再安装。

  ■ 提示没有找到 ZBrush.exe
    → 输入的文件夹不对，请确认文件夹里直接有 ZBrush.exe。

  ■ 窗口提示拒绝访问（Access ... denied）
    → ZBrush 装在 C:\Program Files 下时，写入插件需要管理员权限。
      右键 INSTALL.bat，选“以管理员身份运行”。

  ■ ZBrush 里找不到“局部四边重拓扑”
    → 确认安装时选的是你实际在用的那个 ZBrush，
      然后完全退出 ZBrush 再重新打开。
      仍然没有的话，点 Z脚本 > 加载，选择
      ZBrush 安装目录\ZStartup\ZPlugs64\LocalQuadRetopo.txt
      手动加载一次，以后就会自动加载。

  ■ 执行时顶部提示后台文件缺失
    → C:\LQR 里的文件被删了或被杀毒软件拦截了。
      重新运行 INSTALL.bat；如果杀毒软件拦截 LqrLaunch.exe，
      请把 C:\LQR 加入信任列表。


七、文件清单
----------------------------------------------------------------

  INSTALL.bat              双击运行的安装程序
  Install.ps1              安装程序的实际脚本
  LocalQuadRetopo.txt      ZBrush 插件面板
  LocalQuadRetopo_2022.zsc 给 ZBrush 2022 用的已编译插件面板（如有）
  LocalQuadRetopo_2025.zsc 给 ZBrush 2025 用的已编译插件面板（如有）
  LqrLaunch.exe            在后台启动计算程序，不弹出命令行窗口
  lqr_run_pipeline.py      计算程序入口
  lqr_recover.py           重拓扑主流程
  lqr_validate.py          结果校验
  recovery_geometry.py     四边面配对与加密
  patch_remesh.py          蜂巢布线
  core_patch.py            规则布线
  使用说明.txt             本文件
  用户指南.txt             用法说明
